# RaceTrack-API
O "RaceTrack API 🏎️" é uma aplicação backend desenvolvida em PHP, responsável pelo gerenciamento completo de corridas de kart. A API permite o cadastro de pilotos, pistas, corridas, controle de inscrição de pilotos, registro de voltas e cálculo automático de ranking, melhor volta e vencedor da corrida.
